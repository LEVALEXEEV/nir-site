# Методика

## Единица анализа — прогон

Прогон — 30 с записи кадров (S1, S2), одна холодная загрузка (S3), серия
кликов (S4) или весь свип числа объектов (S5). Из каждого прогона берётся одно
робастное число $x$ — например, медиана времени кадра. Варианты чередуются
в рандомизированном порядке внутри одной серии, поэтому сравнивать можно
только внутри серии.

## Отношение к three.js

Для варианта с прогонами $x_1,\dots,x_n$ и three.js с прогонами $y_1,\dots,y_m$:

$$
r = \frac{\operatorname{med}(x_1,\dots,x_n)}{\operatorname{med}(y_1,\dots,y_m)}
$$

95-процентный доверительный интервал отношения — бутстрап по прогонам
($B = 10\,000$ повторов, фиксированный seed):

$$
r^{*}_b = \frac{\operatorname{med}\bigl(x^{*}_{b}\bigr)}{\operatorname{med}\bigl(y^{*}_{b}\bigr)},\qquad
\mathrm{CI}_{95\%} = \bigl[\,q_{0.025}(r^{*}),\; q_{0.975}(r^{*})\,\bigr].
$$

## Значимость

Критерий Манна–Уитни (не требует нормальности):
$U = \sum_{i,j} \mathbb{1}[x_i > y_j] + \tfrac12\,\mathbb{1}[x_i = y_j]$.
Сравнения внутри платформы поправляются методом Холма: при упорядоченных
$p_{(1)} \le \dots \le p_{(k)}$

$$
\tilde p_{(i)} = \max_{j \le i}\,\min\bigl(1,\,(k - j + 1)\,p_{(j)}\bigr).
$$

## Правило вывода

| Вывод | Условие |
|---|---|
| ≈ равны | $\mathrm{CI}_{95\%} \subset [0{,}95;\ 1{,}05]$ — даже если разница есть, она меньше 5% |
| больше / меньше на X% | $1 \notin \mathrm{CI}_{95\%}$ и $\tilde p < 0{,}05$ |
| не ясно | данных не хватает ни для одного вывода |

## Ёмкость (S5)

Ёмкость при бюджете $T$ ($T = 16{,}7$ мс для 60 FPS, $33{,}3$ мс для 30 FPS) —
число объектов, при котором время кадра достигает $T$. Между соседними
уровнями свипа $N_k < N_{k+1}$ интерполяция ведётся в логарифмах:

$$
N_T = \exp\!\Bigl(\ln N_k + (\ln N_{k+1} - \ln N_k)\,
\frac{T - t_k}{t_{k+1} - t_k}\Bigr).
$$

## Задержка ввода (S4)

Задержка от события до конца отрисовки кадра с подсветкой раскладывается на
последовательные фазы, сумма которых точно равна задержке:

$$
L = t_{\text{queue}} + t_{\text{dispatch}} + t_{\text{commit}} + t_{\text{frame\_wait}} + t_{\text{render}}.
$$
